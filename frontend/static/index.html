Security Architecture
  • Tenant Isolation: Each query is strictly scoped to authenticated_user.organization_id.
  • Credential Security: Database passwords encrypted at rest via AES-256-GCM authenticated cipher.
  • Network Protection: SSRF prevention filters block private IP ranges and internal metadata endpoints.
  • Read-Only Execution: Strictly enforces single-statement SELECT queries with automatic row limiting.
